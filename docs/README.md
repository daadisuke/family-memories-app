## 🚀 クイックスタート

### 初めての方

1. [要件定義書](./requirement.md) でプロジェクトの全体像を把握
2. [セットアップガイド](./setup.md) で開発環境を構築
3. [プロジェクト構造](./project-structure.md) でファイル構成を理解
4. [開発ワークフロー](./workflow.md) で開発の進め方を学習

### 機能開発の前に

1. [データベーススキーマ](./database-schema.md) でデータモデルを確認
2. [API仕様書](./api-spec.md) でAPIエンドポイントを確認
3. [MCP活用ガイド](./mcp-guide.md) で効率的な開発方法を学習
4. [開発ワークフロー](./workflow.md) で具体的な手順を確認

## 💡 ヘルプ・サポート

### 困った時は

1. まず該当するドキュメントを確認
2. ドキュメントに記載がない場合、チームに相談
3. 解決したらドキュメントに追加

### よくある質問

**Q: どのドキュメントから読めばいい?**
A: 初めての方は[要件定義書](./requirement.md)から読み、その後[セットアップガイド](./setup.md)に進んでください。

**Q: MCPって何?**
A: Model Context Protocolの略で、Claude Codeから各種ツールを操作するための仕組みです。詳しくは[MCP活用ガイド](./mcp-guide.md)をご覧ください。

**Q: テーブルを追加したい**
A: [データベーススキーマ](./database-schema.md)を参考に、[開発ワークフロー](./workflow.md)の「データベースマイグレーション」セクションに従ってください。

**Q: 新しいAPIを追加したい**
A: [API仕様書](./api-spec.md)の形式に従って、[開発ワークフロー](./workflow.md)の「機能開発」セクションを参考にしてください。
